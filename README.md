Проект-шаблон для телеграм-ботов на go.

Включает настроенные:
- структуру папок
- загрузка переменных среды
- базовые переменные среды
- логирование с цветом и датами в консоль и файлы с ротацией
- ci
- поллинг для dev среды
- вебхуки на gin для prod среды
- телеграм-диспетчер
- команды /start (ответ "запущено"), /ping (ответ "pong")
- базовый middlware для телеграм (с ограничениями на количество запросов в секунду и минуту)
- клиент Telegram на `github.com/go-telegram/bot`

### Переменные окружения

- `ENV` — режим запуска (`dev` или `prod`).
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
- `HTTP_ADDR` — адрес HTTP-сервера для вебхука (по умолчанию `:80`).
- `TELEGRAM_WEBHOOK_URL` и `TELEGRAM_WEBHOOK_SECRET` — включают режим вебхука.

### Распознавание речи

По умолчанию используется `STT_MODE=omni`: аудио без конвертации передается
как Base64 data URI в `input_audio` на `/chat/completions`.
Ответ запрашивается без streaming, только текст расшифровки.

```dotenv
STT_MODE=omni
OPENAI_API_KEY=<ключ ИИ-роутера Selectel>
OPENAI_BASE_URL=https://api.selectel.ru/aig/v1
OPENAI_STT_MODEL=qwen/qwen3.8-omni-flash
```

ID модели следует сверить с каталогом вашего ИИ-роутера. Поддержку OGG/Opus
и нестримингового аудиозапроса через роутер необходимо проверить реальным
голосовым сообщением. Пока нет конвертации, нарезки аудио или обхода лимитов
провайдера. По документации Qwen Base64 должен занимать менее 10 МБ.

Для прежнего multipart API:

```dotenv
STT_MODE=classic
OPENAI_API_KEY=<ключ STT-провайдера>
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_STT_MODEL=gpt-4o-mini-transcribe
```

Если URL и модель не заданы, выбираются значения по умолчанию для режима.
Явные значения из существующего окружения имеют приоритет: при переходе
обновите и режим, и URL, и модель, и ключ. URL указывается без суффикса API.
Таймаут распознавания — 180 секунд. Длинные ответы отправляются последовательно
частями до 4096 UTF-16 единиц; при ошибке отправка останавливается, ошибка
записывается в журнал. Исходный текст сохраняется без потерь.
